# probes/compat — browser capability record for the E1 slice

Read-only compatibility probe for the drivable E1 page. It answers one question:
**which browsers on which operating systems can actually run this page, and with
which origin, GPU and limits?**

It does not modify `probes/e1-drive/**` or `tools/**`. It serves the unmodified
page through its own server (`0.0.0.0:8812` → `127.0.0.1:8810`), opens it in the
installed browsers with disposable profiles under `_work/compat/profiles/`, and
records what the browser reports.

## Layout

```
probes/compat/
  README.md
  reference/
    requirements.json        # hard requirements, every entry cites file:line
    vendor-support.json      # vendor-documented browser/OS support + sources
    wasm-probes/*.wat        # 13 tiny WebAssembly feature fixtures (sources)
  web/
    capability.html          # probe page
    capability.js            # collects WebGPU/WebGL2/WASM/audio/WS/storage facts
    module-probe.js          # ES module used to prove dynamic import
    wasm-probes.js           # generated by tools/build_wasm_probes.mjs
  tools/
    build_wasm_probes.mjs    # assembles the .wat fixtures with binaryen
    measure_requirements.mjs # draw/texture/buffer budget from committed artifacts
    compat_server.mjs        # /compat/* server + proxy + WebSocket echo
    probe_capabilities.mjs   # launches the installed browsers, records evidence
    build_matrix.mjs         # deterministic support matrix
    verify_compat.mjs        # 637 checks over the record
```

## Commands

```powershell
$node = "_work/toolchains/emsdk/node/24.19.0_64bit/node.exe"

& $node probes/compat/tools/build_wasm_probes.mjs
& $node probes/compat/tools/measure_requirements.mjs
& $node probes/compat/tools/probe_capabilities.mjs          # browsers: all detected
& $node probes/compat/tools/probe_capabilities.mjs --only edge --skip-headed
& $node probes/compat/tools/build_matrix.mjs
& $node probes/compat/tools/verify_compat.mjs
```

## Outputs (not committed)

- `_work/compat/browsers.json` — installed executables + `--version`
- `_work/compat/capabilities/<run>.json` — capability probe per browser/run
- `_work/compat/boot/<run>.json` — real page boot (tick, draws, console, screenshot)
- `_work/compat/screens/<run>-boot.png` — 1280×720 evidence frame
- `_work/compat/render-requirements.json` — measured draw/texture/buffer budget
- `_work/compat/wasm-probes.json` — fixture bytes + SHA-256
- `_work/compat/compat-matrix.json` / `.hash` — derived matrix
- `_work/logs/compat/probe.log` — run log

Ports: `8810` (E1 page server, loopback only), `8812` (probe server, all
interfaces), `8831+` (DevTools). Ports `8801`, `8802-8809` and `8811` are never
used.

## Rules the record follows

- **Measured facts only.** Versions, adapter info, limits, feature support, boot
  results and errors are read from the browser, never from a table.
- **Vendor facts are labelled.** `vendor-support.json` carries its source URLs,
  retrieval date and caniuse note numbers; rows say
  `basis: vendor-documented` and are never mixed with `machine-tested` rows.
- **No guessed minimums.** Where a source gives no minimum (Brave, Chrome for
  Android), the row says `minVersion: null`.
- **Deterministic matrix.** No clock, sorted output, stable hash, rebuilt and
  compared byte-for-byte by the verifier.

Full analysis: `docs/work/analysis/browser-compat.md`.
