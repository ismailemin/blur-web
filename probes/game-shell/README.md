# game-shell — the Blur Web front end

Framework-free menu shell for the E1 drive page. `shell-state.js` is the pure
state machine (no DOM, no timers); `shell.js` renders it and routes DOM events.
`probes/e1-drive/web/menu.js` mounts this module from the drive page, and
`demo.html` + `demo.js` mount it standalone.

```
boot -> main-menu -> mode-select -> car-select -> map-select -> lobby -> loading -> race -> results
```

## Data bindings

Nothing in this directory invents a car, a class or a length. Every value is
read from a committed document:

| input | source | current size |
| --- | --- | --- |
| cars | `probes/e1-drive/cars/roster.json` (drive page: `_work/e1-drive/cars.json`) | **61** of 62 `RP_CarDynamics` records |
| maps | `probes/e1-drive/web/map-registry.js` (`MAPS`) | **13** |
| classes | `data/car-classes.json`, generated by `tools/build-car-classes.mjs` | 61 |
| lengths | `data/course-measurements.json` | 13 maps |

One retail record is not in the roster because the vehicle-batch builder
refused it with a typed reason (`defaultcar` has no body model). It is not
listed and no substitute is used. `hummer-h2-rat` and `ford-supervan-stock`
are now in the roster: the builder decision for each is committed in
`probes/vehicle-batch/spec/cars.json` (orphaned front-right brake elements
resolved by the element matrix translation; rear calipers resolved through the
`E_Brake_Caliper_*` name variant and the `e_wheel_*` parent envelope).

## Car class rule

The class is the vehicle-pipeline **content-completeness class**, not a retail
Blur race class. `tools/build-car-classes.mjs` applies this order:

1. roster positions 0–4 → `A` (the T-007 reference anchors);
2. roster positions 5–14 → `B` (the V1 class-B batch 1);
3. a `high-confidence A|B|C` phrase in the roster `why` → that class (batch 2);
4. otherwise the committed `probes/vehicle-batch/spec/cars.json` entry with the
   same `recordIndex` supplies `class` and `classReason`;
5. otherwise `unclassified`, with the missing source recorded in `provenance`
   and in the `unclassified` map.

Mass, drivetrain and name never select a class; they are display fields only.
`node probes/game-shell/tools/build-car-classes.mjs --check` fails when
`data/car-classes.json` is stale.

Current counts: **A 5 / B 42 / C 14 / unclassified 0**.

## Course measurement rule

`data/course-measurements.json` copies each length from a committed measurement:

- River: the T-007 310.395196 m sprint, 222.040211 m loop-01, 29 m regression and
  7,702.25 m² free-roam basin;
- Amboy: 2,060.595408 m point-to-point and 284.452387 m loop-01
  (`probes/map-laps/data/amboy-loop01-lap.json`);
- Gracia: 624.913781 m;
- Long Beach: 785.823230 m (collision-clear path, not the 818.371718 m draw path);
- Hollywood Hills: 536.621709 m;
- LA Downtown: 153.860674 m;
- Mount Haruna: 309.170196 m;
- Highrise: 14.268660 m;
- Tokyo Shutoko: 279.005135 m;
- Barcelona Oval: 753.021127 m;
- Amboy MP: 122.293808 m;
- Dumbo: 361.999436 m;
- LA Downtown MP: 86.452776 m.

The package-map values equal `MAPS[id].pins.pathLengthMetres`; the gate arcs in
the `gates` section are copied from the same layout's `gates` array. A map that
does not list a course stays visible and disabled with the reason.

## Tests

```powershell
node --test probes/game-shell/test/
```

`data.test.mjs` checks the generated class map, the 61-car coverage, the
unclassified fallback, the 13 map measurements and their provenance.
`state.test.mjs` checks normalisation, filtering/sorting, mode/map support,
start gates, routes and grid navigation. `dom.test.mjs` renders the real 61-car
and 13-map lists through the DOM shim and checks counts, filters, disabled
reasons, focus and the clean console.

## Browser capture

```powershell
node probes/game-shell/tools/capture-shell.mjs
```

Starts the static demo server on 8815 and headless Edge, then captures the main
menu, the 61-car grid and the 13-map grid at 1600x900. It fails on a wrong count,
a horizontal overflow, a missing 7/3-column row, or any console error/warning.
Evidence (three PNGs + `capture-report.json`) lands in `_work/game-shell/` and is
not committed.
