once per draw, not per-draw geometry bounds. Node253's 57 instances collapse to
34 transform-constant groups matching 34 byte-identical records; each group's
union AABB matches its record within `6.024437e-05`. The current one-draw check
therefore rejects 38 instances incorrectly. Planned Stage A/B would raise the
supported total to 36/56 instances respectively; no code change yet. Evidence:
`docs/work/analysis/level-instance-streams.md`.
